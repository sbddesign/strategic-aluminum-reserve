# Strategic Aluminum Reserve

ATL BitLab buys your empty beer cans for sats at **50% of live COMEX aluminum melt value** and pockets the spread. AluminumVision™ (your camera) estimates the grams; payouts go out on MutinyNet via the Voltage CLI.

Live demo: https://honors-planned-scholarship-exercise.trycloudflare.com

Run: `PORT=8787 VOLTAGE_WALLET=<mutinynet-wallet-uuid> node server.js` (needs `voltage login`). Test sats only; mainnet invoices are rejected.
